# 📦 Inventory Management System

A responsive **Inventory Management System** built using **HTML, CSS, Bootstrap, and JavaScript**. This project is designed to help businesses manage products, categories, stock, purchases, and sales through a clean and user-friendly dashboard.

## 🚀 Features

* 🔐 User Registration & Login
* 📊 Dashboard with inventory overview
* 📦 Product Management
* 🗂️ Category Management
* 📈 Stock Management
* 🛒 Purchase & Sales Management
* 🔍 Product Search & Filtering
* ✏️ Add, Edit & Delete Products
* 🌙 Light & Dark Mode
* 📱 Fully Responsive Design
* 💾 Data management using JavaScript
* 🎨 Clean and modern user interface

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Bootstrap 5**
* **JavaScript (ES6)**

## 🎯 Project Purpose

I created this project to practice and strengthen my **JavaScript, DOM manipulation, CRUD operations, responsive design, and real-world web application development skills**.
